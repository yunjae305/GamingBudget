# 가계부 (Android)

웹으로 만든 가계부를 WebView로 감싼 안드로이드 앱입니다. 기록은 기기 안에만 저장되고 서버로 나가지 않습니다.

빌드가 두 가지입니다.

- **개인용(debug)** — APK 한 번만 설치하면, 그 뒤로는 `index.html` 을 고쳐 GitHub에 push할 때마다 앱이 켜질 때 알아서 받아옵니다.
- **스토어용(release)** — 원격 업데이트가 없습니다. 화면은 항상 APK 안의 원본이고, 갱신은 스토어 배포로 합니다. 서명 키가 있어야 빌드됩니다(아래 "스토어에 올리기").

---

## 1. 저장소 만들기

저장소는 https://github.com/yunjae305/GamingBudget 입니다. **공개** 저장소여야 합니다 — 자동 업데이트가 `raw.githubusercontent.com` 주소로 파일을 받기 때문에 비공개로 바꾸면 동작하지 않습니다.

## 2. 업데이트 주소

`app/src/main/res/values/strings.xml` 의 `update_url` 은 이 저장소(`yunjae305/GamingBudget`)의 raw 주소로 설정돼 있습니다. 저장소를 옮기면 이 값을 바꾸고 APK 를 한 번 다시 설치해야 합니다. 직접 운영하는 서버 주소를 넣어도 됩니다.

## 3. APK 받기

1. 저장소의 **Actions** 탭으로 갑니다. `Build APK` 가 자동으로 돌아갑니다. 3~5분 걸립니다.
2. 초록 체크가 뜨면 그 실행을 클릭 → 맨 아래 **Artifacts** 의 `ledger-apk` 를 받습니다.
3. 압축을 풀면 `app-debug.apk` 가 나옵니다.

안드로이드 스튜디오로 직접 빌드해도 됩니다. `ledger` 폴더를 열고 **Build → Build APK(s)**.

## 4. 폰에 설치

1. APK를 폰으로 옮깁니다. (USB, 카카오톡 나에게 보내기, 구글 드라이브 등)
2. 파일 관리자에서 누르고, "출처를 알 수 없는 앱" 설치를 허용합니다.
3. 플레이 프로텍트가 경고해도 **무시하고 설치**를 누르면 됩니다.

---

## 앱 고치기

`app/src/main/assets/index.html` 만 바꾸고 push하면 끝입니다.

```bash
git add app/src/main/assets/index.html
git commit -m "달력 수정"
git push
```

앱을 다시 켜면 새 버전을 받아옵니다.

- 켜자마자 받아지면 바로 적용되고 "새 버전을 받았습니다" 알림이 뜹니다.
- 쓰는 도중에 받아지면 다음 실행 때 적용됩니다. 작업 중에 화면이 갈아엎어지지 않게 한 것입니다.
- 인터넷이 없으면 마지막으로 받아둔 버전으로 그냥 동작합니다.
- GitHub raw 주소는 5분 정도 캐시가 걸립니다. 바로 안 바뀌면 조금 기다리세요.

**APK를 다시 설치해야 하는 경우는 두 가지뿐입니다.** 앱 이름이나 아이콘을 바꿀 때, 그리고 `MainActivity.java` 같은 네이티브 코드를 건드릴 때. (이 설명은 개인용 빌드 얘기입니다. 스토어용은 매번 스토어로 배포합니다.)

---

## 동작 방식

- 최초 실행 때 앱에 들어 있던 `index.html` 을 내부 저장소(`files/live/`)로 복사하고, 이후로는 그 파일을 띄웁니다.
- 내부 저장소와 assets 를 모두 `https://appassets.androidplatform.net` 이라는 같은 오리진으로 서빙합니다. 주소가 고정이라 파일이 갱신돼도 **기존 기록(localStorage)이 그대로 유지**됩니다.
- 새로 받은 파일이 2KB 미만이면 오류 페이지로 보고 무시합니다. 임시 파일에 받아서 통째로 교체하므로 중간에 끊겨도 깨지지 않습니다.

## 결제 알림 자동 감지

카드사·은행·페이 앱 푸시와 결제 문자 알림을 읽어 **결제 대기열**에 넣습니다. 가계부에 바로 저장되지는 않고, 대기열에서 확인하고 일괄 저장합니다.

1. 앱 → 내역 탭 → **결제 대기열**(보라색 버튼)을 엽니다.
2. 알림 접근이 꺼져 있으면 목록 위에 **알림 접근이 꺼져 있습니다 · 켜기** 가 뜹니다. 눌러서 휴대폰 설정의 "알림 접근" 화면에서 **가계부** 를 켜 주세요.
3. 켜고 나면 이 안내는 사라지고, 결제 알림이 올 때마다 앱을 열면 대기열로 들어옵니다. 내역 탭 아이콘에 빨간 숫자로 표시됩니다.
4. 각 건을 눌러 켜고 끌 수 있고, 날짜 머리글을 누르면 그날 전체가 한 번에 켜지고 꺼집니다. 아래 **일괄 저장** 으로 선택한 것만 가계부에 넣습니다.

- 금액(○○원)과 결제 관련 단어(승인·결제·출금·입금 등)가 함께 있는 알림만 모읍니다. 광고, 승인취소, 결제 예정·청구 안내는 거릅니다.
- 처음 켤 때 무엇을 읽는지 설명하는 팝업이 먼저 뜹니다. 알림 내용은 폰 밖으로 나가지 않습니다(`PRIVACY.md`).
- 지원하는 문구 형식은 `tests/parser.test.js` 에 모아 두었습니다(신한·삼성·현대·롯데·하나·우리·농협·KB·토스·네이버페이·카카오뱅크). 안 잡히는 알림이 있으면 그 원문을 거기에 추가하고 파서를 고치면 됩니다.
- 날짜는 알림이 온 시각으로 잡힙니다.
- 카드사 앱 알림이 꺼져 있으면 감지할 수 없습니다. 쓰는 카드사·은행 앱의 결제 알림은 켜 두세요.
- 삼성 기기는 배터리 최적화 때문에 알림 접근이 풀리는 경우가 있습니다. 설정 → 배터리 → 가계부 → **제한 없음** 을 권장합니다.
- SMS 권한은 쓰지 않습니다. 문자는 메시지 앱이 띄우는 알림으로 읽습니다.

## 통계 탭 AI 조언 (선택)

통계 탭 맨 위에 캐릭터가 이번 달 지출을 논평하고 다음 달 조언을 줍니다. 기본은 꺼져 있습니다.

1. 오른쪽 위 ◐ → **설정** → **AI 조언**에서 Gemini API 키를 넣습니다. "키 발급받기"로 Google AI Studio에서 무료로 받을 수 있습니다.
   - 개인용 빌드라면 앱에서 안 넣어도 됩니다. 프로젝트 루트 `.env` 의 `GEMINI_API_KEY=` 뒤에 키를 적고 빌드하면 APK 에 들어갑니다(`.env.example` 참고, 저장소엔 안 올라감). 스토어용에는 기본으로 안 들어갑니다 — APK 를 뜯으면 키가 나오기 때문입니다.
2. 통계 탭에서 **생성하기**를 누르면 그 달 지출 요약(총액·카테고리별 합계·전달 대비 증감)만 키를 통해 Gemini 로 보내고, 코멘트와 다음 달 조언을 받아 보여줍니다. 가게 이름이나 메모는 보내지 않습니다.
3. 한 달에 한 번 생성해 저장해 두고, 화면을 다시 열어도 새로 부르지 않습니다. 다시 만들려면 **다시 생성**을 누르세요.
4. 캐릭터 그림은 `app/src/main/assets/img/character.png` 에 넣으면 나옵니다. 없어도 그라데이션 원으로 대신 보입니다.
5. 키는 이 기기에만 저장되고 백업 파일·자동 백업에는 담기지 않습니다. 자세한 내용은 `PRIVACY.md`.

## 백업

기록은 폰 안에만 있습니다. 두 겹으로 지킵니다.

- **자동** — 저장할 때마다 전체 기록의 복사본을 앱 전용 폴더(`files/mirror.json`)에 둡니다. 안드로이드 자동 백업(Google 계정)과 기기 이전(삼성 스마트 스위치 등)이 이 파일을 새 폰으로 옮겨 주고, 새로 설치한 앱은 기록이 비어 있으면 여기서 되살립니다. 할 일이 없습니다.
- **수동** — 오른쪽 위 ◐ → **설정** → **백업 파일 내보내기**. `가계부-백업-날짜.json` 을 원하는 곳(다운로드, 드라이브 등)에 저장합니다. **백업 파일 가져오기** 로 되돌립니다(지금 기록을 전부 덮어씁니다). 마지막 백업이 며칠 전인지 옆에 표시됩니다.

## 스토어에 올리기

Play 스토어에 올리려면 아래를 차례로 합니다.

1. **서명 키** — `keystore.properties.example` 을 `keystore.properties` 로 복사하고, 안에 적힌 `keytool` 명령으로 키를 만들어 채웁니다. 키 파일은 잃어버리면 같은 앱으로 업데이트할 수 없으니 따로 보관하세요. CI 에서 빌드하려면 GitHub 저장소 Settings → Secrets 에 `LEDGER_KEYSTORE_B64`(`base64 -w0 ledger-release.jks` 결과), `LEDGER_STORE_PASSWORD`, `LEDGER_KEY_ALIAS`, `LEDGER_KEY_PASSWORD` 를 넣습니다. 그러면 Actions 가 `app-release.aab`(스토어 업로드용)와 `app-release.apk` 를 같이 만듭니다.
2. **개인정보처리방침** — `PRIVACY.md` 를 공개 주소(GitHub 페이지나 저장소 파일 링크)로 올리고 Play Console 앱 콘텐츠에 적습니다. 알림 접근 권한을 쓰는 앱은 필수입니다.
3. **데이터 보안 양식** — 수집 없음, 공유 없음, 기기 내 저장. 알림 접근은 "핵심 기능(결제 자동 기록)"으로 사유를 적습니다. 앱 안에서 권한을 켜기 전에 설명 팝업이 먼저 뜨게 되어 있습니다(정책상 요구).
4. **버전** — `app/build.gradle` 의 `versionCode` 를 올릴 때마다 스토어에 새 버전으로 올라갑니다.

## 참고

- 최소 안드로이드 7.0 (API 24)
- 뒤로가기를 누르면 열려 있는 달력·입력창이 먼저 닫히고, 없으면 종료됩니다.
- 데이터는 WebView의 localStorage에 있습니다. 앱을 삭제하면 같이 지워지니, 지우기 전에 백업 파일을 내보내세요.
- 알림 감지가 끊기면 설정(◐)의 "결제 알림 감지"가 **끊김**으로 바뀝니다. 거기서 알림 접근을 껐다 켜거나 **배터리 최적화 제외**를 누르세요.
